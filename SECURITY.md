# Security Policy / セキュリティポリシー

## 脆弱性の報告 / Reporting a vulnerability

LIVE RUSH株式会社が公開しているリポジトリやサービスに脆弱性を見つけた場合は、
**公開 Issue を立てずに**、次の方法でご連絡ください。

- [お問い合わせフォーム](https://www.liverush.co.jp/contact/) から「セキュリティ」と明記して送信
- 対象リポジトリで GitHub の **Security → Report a vulnerability**（Private vulnerability reporting）が有効な場合はそちらから

報告には、影響を受けるリポジトリ・サービス、再現手順、想定される影響を含めてください。
受領後、内容を確認してご連絡します。修正が完了するまで公開は控えていただくようお願いします。

If you find a vulnerability in a LIVE RUSH repository or service, **please do not open a public issue**.
Use the [contact form](https://www.liverush.co.jp/contact/) (mention "security") or GitHub's private
vulnerability reporting where enabled. Include the affected repository or service, reproduction steps,
and expected impact. We will confirm receipt and follow up; please hold disclosure until a fix is in place.
